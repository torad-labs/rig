# docs/

The map of the program, for a person: `architecture.md` says what the layers are, what each
slice decides, the invariants the code holds, the exit codes, and how a head is added.

**Belongs here:** documents about how rig is built and why, written for a reader who has the
tree open. One document per subject; `architecture.md` is the only one today.

**Does not belong here:** product truth (`/PRODUCT.md`), the front door (`/README.md`), a
head's numbers and their provenance (`heads/<head>/evidence.md`), the rules of a folder (that
folder's `README.md`), generated output of any kind, and notes from an experiment (the project
wrapper's `research/`, outside the repo).

A document here describes the tree as it is. When the tree changes, the document changes in
the same commit.
